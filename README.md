## 💡 Бизнес-ценность
Знание настоящих и будущих доходов своих клиентов позволяет банку своевременно принять меры, чтобы минимизировать свои риски. В зависимости от динамики доходов клиента могут быть приложены различные стратегии, которые позволят максимизировать прибыль и снизить риски:
- Автоодобрение кредитов
- Оформление кредитов/кредитных карт без справок и кучи документов
- Инвестиционные предложения и планы
- Предложения рефинансирования
- Управление лимитом текущего кредита
- Оценка приемлемого лимита вновь выдаваемого кредита
- Оценка наиболее прибыльной с учетом рисков и привлекательности для клиента ставки кредита
- Дополнительная проверка надежности клиента
- Запрос дополнительных документов
- Автоотказ по кредитам
- и другое

Для помощи в принятии таких решений и создана наша модель. Данная модель и интерфейс могут применяться в колл-центрах банка для помощи сотрудникам в поисках уместных предложений клиентам или в качестве api-сервиса банка для принятия соответствующих ситуации решений, подборе персонализированных предложений в личном кабинете клиента.

## 🎯 Как продемонстрировать работу модели

### Вариант 1: Использование ID клиента из базы данных

1. **Откройте интерфейс**: Перейдите на http://localhost
2. **Введите ID клиента**: В поле поиска введите числовой ID клиента (например: `1`, `123`, `456`)
3. **Нажмите "Анализ"**: Система запросит данные клиента из базы данных и выполнит предсказание
4. **Просмотрите результаты**:
   - **Прогнозируемый доход** — предсказание модели в рублях
   - **Изменение дохода** — процент изменения относительно текущего дохода
   - **Уверенность модели** — оценка надежности предсказания
   - **Сегмент клиента** — автоматически определяется на основе дохода
   - **SHAP-график** — показывает топ-5 факторов, влияющих на предсказание

### Вариант 2: Использование прямого API-запроса

Если у вас нет данных в базе, вы можете отправить POST-запрос напрямую в API:

```bash
curl -X POST "http://localhost/api/predict/" \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": 1
  }'
```

### 📊 Что показывает интерфейс:

- **PredictionCard**: Основная карточка с прогнозом дохода, изменением в процентах, уверенностью модели и сегментом клиента
- **SHAPChart**: Визуализация топ-5 факторов, влияющих на предсказание (положительные и отрицательные вклады)
- **RecommendationList**: Персональные финансовые рекомендации (в разработке)

### ⚠️ Важные замечания:

- Для работы с ID клиента необходимо, чтобы в базе данных была таблица `client_features` с соответствующими данными
- Если клиент не найден в базе, используйте вариант 2 с прямым указанием признаков
- Модель требует множество признаков (см. `backend/app/ml/artifacts/feature_schema.json`), но может работать и с неполными данными (пропущенные значения обрабатываются автоматически)
